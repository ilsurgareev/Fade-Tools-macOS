# Fade Tools — состав исходников для переноса

Этот архив содержит исходный код внешней программы для открытия видеофайлов, предпросмотра Fade, задания In/Out и постановки отрывков в очередь рендера. Это подготовка исходников для дальнейшей работы на MacBook, а не macOS-порт: приложение пока сохраняет Windows-специфичные участки, и инструкции по сборке или запуску на macOS сюда не включены.

## Что включено

- Окно Fade Settings и отдельная рабочая область видео с воспроизведением, шкалой, перетаскиваемыми In/Out, настройками Fade и предпросмотром.
- Очередь отрывков с сохранением ожидающих заданий, проверкой файлов и безопасной публикацией результата.
- `droplet.py` — оконно-незаметный обработчик файлов через FFmpeg/FFprobe; общие модули настроек, медиапроверок, планирования, временных меток и Fade.
- Тесты конфигурации/медиа, предпросмотра, таймлайна, очереди, прогресса и оконного интерфейса. `test_fade.py` в архиве содержит только тесты внешней обработки и не включает Resolve API-проверки.
- `requirements.txt`, `pytest.ini`, описание сторонних компонентов и тексты GPL/LGPL лицензий.

Копия `settings_app.py` в архиве очищена от кнопки «Fade в Resolve», обработчика запуска Resolve и импортов, нужных только ему. Файлы в исходном Windows-проекте не изменялись.

## Что намеренно исключено

Не включены Resolve API, `resolve_fade.py`, `resolve_render.py`, `resolve_launcher.py`, `render_launcher.py`, `render_plain.py`, `render_with_fade.py`, вспомогательные сценарии применения Fade к таймлайну или запуска Resolve-рендера, Resolve-специфичные тесты, доставка Reels/TG Bot и Windows-сборочные артефакты. В архивной копии интерфейса нет кнопок или вызовов Resolve.

Также исключены EXE и другие бинарники, `dist`, `build`, `.venv`, кэши, временные данные, видео/проекты пользователя, очереди и настройки пользователя, логи и секреты.

## Зависимости исходного Windows-проекта

- Python 3.12 (использовался для текущей версии проекта).
- PySide6 6.12.0, включая Qt Multimedia для видео/звукового предпросмотра.
- FFmpeg и FFprobe: внешние инструменты обработки, probe, предпросмотра и проверки. Их бинарники в архив не входят.
- pytest 9.1.1 для тестов.
- PyInstaller 6.22.3 указан в исходном `requirements.txt` для существующей упаковки проекта; этот архив не задаёт способ сборки для macOS.

## Как устроены основные модули

- `settings_entry.py` — точка входа окна настроек и запись ошибки старта.
- `settings_app.py` — настройки Fade и экспорта; запускает встроенную рабочую область клипов.
- `clip_window.py` — проигрыватель, шкала и ручки In/Out, приблизительный живой предпросмотр, очередь и её сохранение.
- `live_fade.py`, `frame_time.py`, `clip_plan.py` — вычисление огибающих Fade, отображение времени/кадров и правила диапазона/имени результата.
- `clip_engine.py` — подготовка кандидата FFmpeg, проверка метаданных и полного декодирования, затем безопасная публикация.
- `media.py` — команды FFmpeg/FFprobe, проверка потоков, фильтры Fade и правила кодирования; используется также Droplet.
- `config.py` — схема, проверка и сохранение настроек/пресетов.
- `droplet.py`, `notify.py` — пакетная обработка файлов и уведомления/логи текущей Windows-версии.

## С чего начать изучение

Прочитать этот файл, затем `settings_entry.py` и `settings_app.py` для входа в приложение; после этого `clip_window.py` для UI/очереди и `clip_plan.py` → `clip_engine.py` → `media.py` для подготовки и публикации видео. Для проверки соответствующих контрактов смотреть `test_unified_ui.py`, `test_manual_queue.py`, `test_clip_plan.py`, `test_clip_engine.py` и `test_fade.py`. `droplet.py` показывает отдельный файловый сценарий.
