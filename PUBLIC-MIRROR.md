# Публичное зеркало исходников macOS

Workflow `../.github/workflows/publish-macos-mirror.yml` публикует содержимое
этой папки в отдельный публичный репозиторий `ilsurgareev/Fade-Tools-macOS`.
Основной репозиторий `Fade-Tools` при этом остаётся приватным.

## Однократная настройка владельцем

1. Публичный репозиторий `Fade-Tools-macOS` с веткой `main` уже создан и содержит
   macOS-исходники.
2. Для автоматической синхронизации исходников создать Fine-grained personal access token только для этого репозитория,
   разрешив `Contents: Read and write`. Не добавлять токен в исходники.
3. В настройках приватного `Fade-Tools` добавить Actions secret
   `MACOS_MIRROR_TOKEN` со значением токена.
4. Первый запуск workflow уже прошёл успешно. Каждый push изменений в `macOS/`
   ветки `macOS` автоматически обновляет ветку `main` публичного зеркала.

Workflow копирует только `macOS/`, не переносит историю приватного проекта и
не публикует содержимое остальных веток или папок.

## Важные ограничения

- Зеркало делает исходный код macOS публичным. Перед включением синхронизации
  проверьте, что в `macOS/` нет секретов или материалов, которые нельзя
  публиковать.
- Этот канал публикует исходники. Автообновление установленного `.app` требует
  отдельной сборки подписанного релиза, публичного manifest/asset и безопасного
  установщика. Само зеркало не устанавливает обновления на компьютерах.
- Для production рекомендуется закрепить используемые GitHub Actions по
  проверенным commit SHA и добавить проверку состава публикуемых файлов.
