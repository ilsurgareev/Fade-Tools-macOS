# Fade Tools для macOS

Комплект для Apple Silicon (M1/M2/M3/M4 и другие arm64 Mac), macOS 14.4 или новее.

## Передача другому человеку

Передайте [ZIP из публичных macOS Releases](https://github.com/ilsurgareev/Fade-Tools-macOS/releases/latest). Получатель распаковывает ZIP и открывает `Fade Tools.app` либо `Fade Droplet.app`. Обе программы содержат Python, Qt, FFmpeg, FFprobe и необходимые библиотеки. Установка Homebrew, Python, FFmpeg и загрузка компонентов при первом запуске не требуются. Приложения можно перенести вместе или по отдельности в «Программы».

Fade Tools автоматически проверяет публичный канал при запуске. Кнопка проверки находится в верхней части правой панели. При наличии новой версии приложение предложит скачать её, проверит SHA-256 архива, затем закроется и заменит свою копию приложения с возможностью отката при ошибке. Если программу запустить из исходников, кнопка откроет страницу релиза в браузере.

Это локально подписанная сборка без нотариализации Apple. Если macOS блокирует открытие, используйте «Системные настройки → Конфиденциальность и безопасность → Всё равно открыть» для полученной от доверенного отправителя программы.

Схема отдельного публичного зеркала macOS описана в [PUBLIC-MIRROR.md](PUBLIC-MIRROR.md). Она публикует исходники из этой папки в отдельный репозиторий; публикация `.app` и автоматическая установка обновлений на компьютер настраиваются отдельно.

## Рендер

По умолчанию выбран Apple VideoToolbox. Если аппаратное кодирование завершается ошибкой, незавершённый временный результат удаляется и задача один раз повторяется на CPU. Результат проверяется перед сохранением в обоих режимах. Можно выбрать CPU вручную. Старые настройки предыдущей macOS-сборки автоматически переводятся в аппаратный режим с резервом CPU.

Fade Droplet принимает несколько видео перетаскиванием на значок, в окно или через кнопку выбора. Используются настройки Fade Tools; файлы обрабатываются по очереди. Закрытие окна во время работы блокируется до завершения обработки. Добавленные в работающий Droplet следующие файлы ждут завершения текущей группы.

Настройки и очередь основной программы: `~/Library/Application Support/FadeTools/`. Логи находятся там же в `logs/`. Сохранение очереди основной программы действует после перезапуска; очередь Droplet существует только пока открыто его окно.

Повторный рендер того же исходника с точными одинаковыми In/Out заменяет известный результат. Старые файлы без метки диапазона и результаты с другими границами защищены. Droplet всегда подбирает свободное имя.

## Разработка и сборка

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements-build-macos.txt
.venv/bin/python settings_entry.py
.venv/bin/python droplet_entry.py
QT_QPA_PLATFORM=offscreen QT_MEDIA_BACKEND=ffmpeg .venv/bin/python -m pytest
.venv/bin/python build_macos.py
```

При сборке используются автономные FFmpeg/FFprobe из `tools/`: сборщик включает их вместе с библиотеками в каждый `.app` и исправляет пути к зависимостям. Результат — `dist/Fade Tools.app` и `dist/Fade Droplet.app`. Проверяйте автономный запуск и зависимости после каждой смены версии FFmpeg. Уточнение версий и лицензий — в `THIRD_PARTY.md`.
