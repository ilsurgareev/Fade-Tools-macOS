# Проверка передачи macOS

Проверено 28 октября 2026 на текущем Apple Silicon Mac.

- PySide6/Qt 6.8.3, Python 3.12, автономные FFmpeg/FFprobe 9.0.
- Полный набор: 107 passed, 3 skipped (NVIDIA NVENC не поддерживается на macOS).
- Реальный рендер H.265 через Apple VideoToolbox с полной проверкой декодирования успешен.
- Ошибка аппаратного кодирования: CPU-повтор проверен на реальном ограниченном запуске и отдельными тестами. Частичный временный результат удаляется. Отмена не запускает повтор.
- Три ручные мутации (удаление очистки, отключение повтора, перехват отмены) обнаружены целевыми тестами; исходный код восстановлен.
- FileOpen-события macOS доставляются дроплету и объединяются в группу; обработка выполняется в фоне.
- Финальный ZIP распакован в отдельный временный каталог. Из него запущены обе программы с чистыми настройками, дроплет создал проверенный H.265, выбирая вложенные FFmpeg/FFprobe при PATH без Homebrew.
- Подписи обоих приложений проверены codesign --verify --deep.
- Проверены все Mach-O: внешних путей к Homebrew и другим несистемным библиотекам нет. Минимальная версия в бинарниках не превышает macOS 12.0; в Info.plist консервативно заявлена macOS 14.4.

На macOS 14/15 физический запуск пока не выполнялся. Локальная подпись не является Developer ID подписью/нотариализацией Apple.

Присланный отчёт Python SIGABRT в qDetectCpuFeatures совпал с тестовым запуском Qt 6.8 под ограничениями чтения CPU. При обычном доступе библиотека и приложения запускаются успешно; итоговые проверки и сборка выполнены с таким доступом.
